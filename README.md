# Porkify

Porkify is a large Balatro content mod built around strange synergies, new
run-defining choices, and a little extra chaos. It expands nearly every part of
the game while keeping the pace and feel of a normal Balatro run.

## What It Adds

- A large collection of custom Jokers and Consumables
- New decks, Boss Blinds, Booster Packs, Vouchers, Stakes, and Challenges
- New Enhancements, Editions, Seals, and Stickers
- 22 secret poker hands that reveal themselves when first played
- 36 custom achievements
- Optional balance tweaks and gameplay settings

Individual cards include their art and idea credits in-game.

## Requirements

Porkify requires
[Steamodded](https://github.com/Steamodded/smods) `1.0.0~BETA-1620a` or newer.

## Installation

1. Install Steamodded.
2. Place the Porkify folder in Balatro's `Mods` folder.
3. Launch Balatro and enable or configure Porkify from the Mods menu.

## Multiplayer

Porkify supports the optional Balatro Multiplayer mod. Unsafe PvP content is
automatically banned where relevant, adjusted cards are shown in Multiplayer's
Reworked screen, and seeded gameplay pools are kept deterministic. Both players
should use the same Porkify version, gameplay settings, and fully unlocked
profiles.
